Each project is rated across four dimensions — Schedule · Budget · Scope · Quality — plus one Overall RAG that is the single source of truth for project health. The four dimension dots inform the narrative; only the Overall dot drives the global portfolio colour.

Automated Visual Cues & Dashboard Navigation
C
Automated UI States — What to Look For
🔴
Pulsing Red Badge — Decision Due Soon
Appears on Executive Asks in Section D. The badge animates with a repeating red glow when a decision is due within the next 7 days. A solid red badge labelled OVERDUE appears once the date has passed.
⚡ PULSES WITHIN 7 DAYS OVERDUE — PAST DUE DATE
🟢
LIVE Indicator — Data is Current
A small pulsing green dot in the top-right of the masthead confirms the dashboard is connected to live data and last refreshed successfully (auto-refreshes every 5 minutes).
● LIVE · [timestamp] STALE — connection lost
⚑
Gold Key Flag Banner — Headline Announcement
A gold banner appears below the project scorecards when the Portfolio Coordinator has set a weekly headline (e.g. gate approvals, critical decisions made). Hidden when there is no announcement.
⚑ KEY FLAG: [headline text]
🔅
Dimmed Row / Card — Completed Project
A project row in the matrix and its scorecard card are displayed at reduced opacity when the project has been marked complete by the Portfolio Coordinator. It remains visible for reference but signals no further action is needed.
COMPLETE — reduced opacity
🔵
Deep Dive Link — Direct to Source
Each project in the matrix has a coloured "Deep Dive" button. Clicking it opens the linked MS Teams Planner board or SharePoint page for that project directly in your browser. The button label may be customised per project.
↗ M365
☀
Dark / Light Theme Toggle
The ☀ button in the top-right masthead switches between the default dark theme and a light theme. Your preference is remembered for the current browser session.
☀ LIGHT · ☽ DARK
🔤
Font Size Controls — A− / A+
Two buttons in the masthead scale the entire dashboard smaller or larger across seven steps (82%–122%). Useful on high-resolution screens or when presenting on a projector. Preference is saved for the session.
A− smaller · A+ larger
⎙
Print / Export to PDF
The ⎙ button opens the browser's print dialog. Interactive controls, the filter bar, and the help panel are hidden automatically — only portfolio content is printed. Use "Save as PDF" in the print dialog to produce a shareable file.
⎙ PRINT / SAVE AS PDF
⌕
Project Matrix Filter Bar — Search & RAG Chips
A search box and RAG chip buttons (Green / Amber / Red / Hold) sit above the project matrix. Type a project name to narrow the rows, or click a chip to show only projects at that health status. Click All to reset.
● Green ● Amber ● Red
D
Dashboard Layout — Section by Section
A
The Pulse — Portfolio Delivery Health
Global RAG orb + project scorecards + Key Flag banner. Read this first — it's the one-number summary of the whole portfolio.
B
Project Matrix
All active projects in a single table. Compare phase, schedule status, four-dimension RAG, next milestone, and links to detailed plans side by side.
C
Upcoming Milestones
Chronological list of portfolio milestones. Colour-coded by type (go-live, review, approval, decision). Upcoming milestones appear first, sorted nearest date at the top. Past milestones appear in a dimmed "Past" section below — visible for reference but clearly separated.
D
Executive Decisions / C-Suite Asks
Open items requiring a decision or action from leadership. Each shows the ask, context, due date, and the project it belongs to. Check this section for any pulsing items.
E
Cross-Project Risks & Dependencies
Risks being tracked across the portfolio. Severity levels: HIGH · MED · LOW · DEP (dependency) · ESC (escalated) · WATCH.
