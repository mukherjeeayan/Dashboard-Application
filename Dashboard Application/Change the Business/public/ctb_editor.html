How to Use the Editor
Everything you need to know to manage your Change-the-Business Portfolio data.
Getting Started

The editor lets you modify the portfolio data that powers the CTB dashboard. All changes are made in memory — nothing is saved until you download the updated JSON file.

  1. Import your current data/ctb_data.json via the topbar button (or start from the example seed data).
  2. Edit fields using the pencil icons in each panel.
  3. Download the updated JSON and replace public/data/ctb_data.json in your project.
Always import your live data first — the seed data is just a template. Look for the amber warning bar at the top.
Panels Overview
Meta — Report title, period, date, confidentiality, and owner info.
Pulse — The key flag statement shown at the top of the dashboard.
Projects — Add, edit, delete projects. Set RAG status, phase, sub-phase, schedule, and notes.
Milestones — Key dates with types (Milestone, Review, Approval, etc.).
Risks — Track risks, watchpoints, and dependency owners. Link them to affected projects.
Decisions — Outstanding asks with due dates, project links, and context.
Editing Fields

Each field has an edit button (pencil icon). Click it to switch to edit mode, make your changes, then click the checkmark to save or the X to cancel. Keyboard users can press Enter to confirm and Escape to cancel (in most text fields).

  • Text fields — freeform input with character limits.
  • Dropdowns — Phase, Sub-Phase, RAG values, Schedule Status, Risk Level, and more.
  • Dates — Use the browser's date picker; stored as YYYY-MM-DD.
  • Date+Time — Used for Last Updated; stored as YYYY-MM-DDTHH:MM:SS.
Adding & Removing Items

Use the + Add button at the top-right of each portfolio panel (Projects, Milestones, Risks, Decisions) to create a new item. New items are added to the end of the list and opened for editing immediately.

To remove an item, click the delete icon (trash can) on any item card. A confirmation dialog will appear before deletion.

Deleting a project will also remove any decisions linked to that project to keep data consistent.
Import & Export
Import JSON Load an existing ctb_data.json file. Validates the structure and shows a summary before importing. Replaces all current data.
Download JSON Save your edited data as a timestamped .json file. Replace public/data/ctb_data.json in your project to update the dashboard.
Preview JSON Inspect the full JSON output in a syntax-highlighted modal before downloading.
Dismiss Seed Warning If you're intentionally starting from seed data, you can dismiss the amber warning bar.
