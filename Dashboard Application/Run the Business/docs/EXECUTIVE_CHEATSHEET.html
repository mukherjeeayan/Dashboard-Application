SAP CRM · IT Operations Dashboard — Executive Reference

IT Portfolio Management Office  ·  Prepared 28 May 2026

Section 1 — Reading the Dashboard at a Glance

RAG Status Indicators

Every ServiceNow card and KPI tile carries a RAG (Red–Amber–Green) dot indicating the operational health of that category. RAG is set by the Data Steward based on actual figures versus the defined thresholds in snow_config.json.

Red — Action required. Threshold breached. Leadership intervention may be needed.
Amber — At risk. Approaching threshold. Active monitoring required.
Green — On track. Operating within defined parameters.

KPI Tile — How to Read It

Each KPI tile shows four elements:

  • Large value — the current week's count or percentage, coloured by RAG status.
  • Delta arrow — movement since last week. ▲ = increase, ▼ = decrease, — = flat. For incidents/problems, ▲ red is worse. For SLA, ▲ green is better.
  • Progress bar — volume relative to the configured maximum for that category.
  • Label — the metric name (e.g., "Open Incidents", "SLA Compliance").

SLA Compliance — Special Inversion Logic

SLA Compliance uses inverted delta colouring because higher is better:

  • ▼ red = SLA dropped week-on-week — bad.
  • ▲ green = SLA improved week-on-week — good.
  • Target threshold is 90%. Amber: 85–90%. Red: below 80%.

Section 4 — RAG Cascade & Escalation Logic

How RAG Status is Determined

RAG status on each ServiceNow card and KPI tile is set by the Data Steward based on thresholds defined in snow_config.json. The thresholds for the current deployment are:


MetricGreenAmberRed
SLA Compliance≥ 90%85–89%< 80%
PRB SLA (days open)< 37 days37–44 days≥ 45 days
PRB SLA Breached Count0–12–4≥ 5

Cascade Principle — Single Red Propagates Upward

If any one operational dimension breaches its Red threshold, the overall status for the reporting period is considered Red regardless of other dimensions. This is the cascade principle:


Green SLA Compliance: 91% — within target
Green Incident Volume: 42 — within max
Red P1 Count: 3 — breached threshold
↓ single red dimension cascades
Red Overall Period Status: RED — leadership action required
Section 5 — Abbreviation & Term Glossary
RAG
Red / Amber / Green. Standard portfolio status signalling system. Red = act now, Amber = watch closely, Green = on track.
INC
Incident. An unplanned disruption or degradation of IT service quality. Tracked in ServiceNow with priority, state, and SLA.
SR
Service Request. A formal, pre-approved request for standard IT service. Distinct from incidents — these are expected demand.
PRB
Problem record. Root-cause investigation for repeated or high-impact incidents. Remains open until a permanent fix is implemented.
RFAC
Request for Authorised Change. The formal change management record requiring CAB sign-off for high-risk modifications.
CAB
Change Advisory Board. Governance body that reviews and approves high-risk changes before implementation.
SLA
Service Level Agreement. A contractual commitment on response and resolution times. Dashboard target: ≥ 90% compliance.
WoW
Week-on-Week. Comparison of the current week's figures against the prior week and rolling 8-week trend.
PI / PO
SAP Process Integration / Process Orchestration. The middleware layer connecting SAP CRM to external systems. Integration incidents often have wide business impact.
pp
Percentage point. The absolute difference between two percentage values (e.g., SLA moving from 88% to 91% = +3 pp, not +3.4%).
CW
Calendar Week. ISO week number (1–53). W22 = the 22nd week of the calendar year. Used for archive naming and portable build filenames.
Portable Build
A self-contained single HTML file produced by the Launcher compiler. Contains all data, styles, and scripts inline. Can be opened in any browser without a server. Distributed to stakeholders who cannot run the live server.
