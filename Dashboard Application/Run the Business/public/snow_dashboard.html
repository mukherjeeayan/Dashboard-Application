📋 How to Update This Dashboard — Edit snow_weekly.json Only

Quick Start

  • Open snow_weekly.json in VS Code, Notepad++, or any text editor
  • Edit only the values — do NOT rename any keys
  • Save the file, then refresh the browser (F5)
  • Never touch snow_dashboard.html — all data lives in the JSON
  • The JSON has an _instructions block at the top with a full checklist

Weekly Update Checklist

  • meta — update week_label, week_range, data_as_of
  • kpis — update value, bar_pct, delta_val, delta_dir
  • snow_links — update stats[] values per card
  • charts — replace all data arrays with this week's numbers
  • wow_scorecard — append new week; drop oldest if > 8 weeks
  • intervention — replace items[] (use [] if none)
  • commentary — rewrite each column's items[]

Allowed Values

  • color_key / color: "red" | "amber" | "green" | "blue" | "purple" | "muted"
  • delta_dir: "up" | "down" | "flat"
  • rag: "red" | "amber" | "green"
  • severity: "red" | "amber"
  • delta_unit: "pp" for percentage-point rows, omit otherwise

Adding a Commentary Bullet

Append to any column's items[]:

{
  "tag": "RISK",
  "tag_color": "red",
  "text": "Plain text. <strong>Bold</strong> allowed."
}

Adding an Intervention Item

severity: "red" or "amber". Append to intervention.items[].

{
  "severity": "red",
  "badge_label": "ESCALATE NOW",
  "title": "Short headline",
  "meta": ["INC0012345", "SAP SD"],
  "body": "Impact description.",
  "decision": "Action required.",
  "raised_by": "Name · Role",
  "avatar": "NR",
  "age_label": "2d open",
  "age_color": "red"
}

Updating Charts

  • incident_trend_8w — shift labels left, append new week
  • incident_by_priority — update data[] by priority
  • sr_by_category — update labels[] and data[]
  • rfac_pipeline — update data[] for pipeline stages
  • prb_aging — replace records[] with open PRBs
  • incidents_by_module — update data[] per SAP module
  • wow_volume / wow_sla_trend — append week; drop oldest if > 8
