Welcome to the SNOW Dashboard Editor

Your step-by-step guide to building the weekly IT Operations dashboard.

🧭 What this tool does

This editor takes your ServiceNow weekly extracts (Incidents, Service Requests, RFCs, and Problems) and turns them into a ready-to-use dashboard JSON file. You work through five simple stages — from setting your target week all the way to downloading the final file. No coding required.

⚙️

1. Configuration

Set your target ISO week, timezone, SLA thresholds, priority maps, and ServiceNow instance URLs. This is where you tell the tool what "good" looks like.

📂

2. Data Upload

Upload your INC, SR, RFAC, and PRB Excel or CSV extracts. The tool validates each file automatically and shows you a coverage overview so you know nothing is missing.

📊

3. Calculated KPIs

Review the week-over-week KPIs computed from your data — volumes, SLA achievements, RAG ratings, and breach trends. Everything is calculated automatically.

✏️

4. Manual Sections

Add your weekly summary commentary, leadership intervention notes, and the WoW RFAC scorecard. These sections give context to the numbers.

📦

5. Generate JSON

Review the final checklist, download the snow_weekly.json file, and drop it into the dashboard viewer.

📄

Load Previous JSON

Already have a previous week's JSON? Click Load Previous JSON in the top bar to pre-fill config and manual sections so you only update what changed.

💡 Tips for a smooth run

  • Complete the steps in order — the tool will unlock each stage as you go.
  • Your work is auto-saved in your browser's local storage. Closing the page won't lose it.
  • Use the Upload Config JSON option in the Configuration panel to reuse settings week over week.
  • Upload files should cover at least 8 weeks of data for proper WoW comparisons.
  • Need to start fresh? Use the Reset All button (top-right) to clear everything.
